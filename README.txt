RAJA VIP animated cricket landing page

Included files
- index.html: the mobile-friendly page styled to match the RAJA VIP poster sample
- assets/raja-photo.jpg: the supplied portrait used on the page

How to preview
1. Extract the ZIP file.
2. Open the raja-vip-landing folder.
3. Double-click index.html. It opens in your browser.

Telegram button
The Join button opens https://t.me/Raja_Vipbot?start=join.
The Telegram bot must be configured to reply to /start and provide the channel invite link.
The channel invite link was not provided yet, so the page opens the bot first.

To change the bot username/link, open index.html and replace both occurrences of:
https://t.me/Raja_Vipbot?start=join

To replace the portrait, overwrite assets/raja-photo.jpg with your new image,
keeping the same filename.
